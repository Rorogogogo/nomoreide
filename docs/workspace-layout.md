# Workspace panes

Use **Open beside** in the workspace tab bar to choose a page for a second pane.
For example, keep Services on the left and open GitHub on the right, select a
project, then select GitHub's Actions tab. Both visible pages continue refreshing.

- The **+** menu opens a tab in that pane. Sidebar navigation opens a tab in the
  focused pane. Click inside a pane to focus it.
- Selecting a destination already open focuses its existing tab. Open beside
  moves an existing primary tab to the second pane when another primary tab remains.
- Drag the divider to resize. With the divider focused, use Left/Right to resize,
  Home/End for the limits, or double-click to return to equal widths.
- Use Left/Right or Home/End on a focused tab to select another tab.
- Close tabs with their × button. Closing the last tab in either split pane
  collapses it. The second pane's **Return to one pane** button combines all tabs.
- Tabs retain their local state while switching. Hidden tabs suspend their effects;
  the shared agent terminal dock remains available below both panes.

The browser saves tabs, focused pane, and divider width per selected repository.
A project with no saved layout inherits the current arrangement. Storage failures
fall back to an in-memory layout. Explicit page links still open their destination.
At narrow window widths, the panes stack vertically.
