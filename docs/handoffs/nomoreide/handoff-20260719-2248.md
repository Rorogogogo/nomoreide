## Key decisions and constraints

- Global tracking covers user-triggered mutations only, not background fetches or polling.
- Button feedback is immediate; the global activity strip appears only after about 300 ms to prevent flicker.
- The app remains interactive. Do not add a blocking overlay or fake progress percentage.
- Extend the canonical `src/web/client/src/components/ui/button.tsx`; do not add another competing button primitive.
- Error Inbox becomes searchable, filterable, and expandable while preserving SSE status, project scoping, incident grouping, Fix with AI, Review Changes, localization, and accessibility.
- Reuse the 21st.dev component's information architecture, not its demo data, full-screen shell, hardcoded English, or simulated status/duration model.
- The project already supports shadcn structure, Tailwind CSS, TypeScript, Framer Motion, and Lucide. UI alias resolves to `src/web/client/src/components/ui`.
- Follow TDD and commit in small, reviewable units as specified in the plan.
