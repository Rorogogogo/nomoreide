Implemented behavior:

- One child-owning supervisor per generation; natural exits are reaped and reported as `Exited`.
- Per-service async lifecycle serialization and generation fences for state/URL callbacks.
- Awaited TERM→KILL process-tree shutdown; cleanup failure stays retryable/fail-closed.
- Unix process-group cleanup confirms both child reaping and group disappearance.
- Windows uses `CREATE_SUSPENDED`, assigns the still-suspended root to a kill-on-close Job Object, then resumes it; ActiveProcesses confirms tree cleanup.
- Start/restart supports structured port conflict handling with exact PID, command, and kernel birth-token revalidation plus managed/app/system/UID protection.
- Optional versioned/private native runtime registry and verified orphan cleanup scaffolding.
- Tauri close now waits for terminal and service shutdown and refuses exit on cleanup failure.
- Dashboard adapter understands the new `exited` state.

Focused regressions cover natural reaping, crash restart, concurrent starts, generation-safe restart, TERM-resistant parent/descendant cleanup, dead-leader/live-group recovery, missing-supervisor fail-closed behavior, registry generation ownership/corruption, non-destructive port conflicts, protected holder policy, and real stale/exact port-holder termination.

## Key decisions and constraints

- Pragmatic architecture: per-generation supervisor plus per-service operation lock, not a global actor rewrite.
- Daemon remains the intended sole owner of live runtime state. Current production Rust mutation ownership is still Tauri; this slice repairs core behavior without changing transport ownership.
- The native registry is dormant scaffolding until a daemon owner supplies it. Do not claim production daemon-crash recovery yet.
- The native registry is deliberately versioned and must use a dedicated native path; it is not compatible with or wired to TypeScript `~/.nomoreide/runtime.json`.
- Preserve argv execution, protected-process/expected-identity checks, loopback/private-credential behavior, daemon owner pinning/revalidation, and MCP stdout purity.
- Do not expose arbitrary commands, boolean-only holder killing, or broad process mutation.
- TypeScript remains the behavioral reference until each new black-box parity slice passes.
