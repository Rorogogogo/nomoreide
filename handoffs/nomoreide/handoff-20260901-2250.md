## Failed approaches

- **Do not have the relay dispatcher call core APIs directly.** The original
  plan says to; the revision reverses it. That is exactly what
  `nomoreide-tauri` did and it drifted into 150 duplicate commands and a
  feature that silently became a stub. Route through the daemon's own router
  in-process, against an explicit allowlist.
- **`perl -0pi -e` mangles JS/TS template literals** — `${name}` interpolates
  as a perl variable and silently empties. Bit me four times. Write whole files
  with a heredoc, or escape as `\$\{name\}`.
- **macOS has no `timeout`.** Scripts that use it fail with "command not found".
- **`lsof -ti:PORT` returns client connections too**, not just the listener. Use
  `lsof -nP -iTCP:PORT -sTCP:LISTEN` when you mean the owner.
- **crates.io returns 403 without a User-Agent** — not 404, so a naive "does
  this crate exist" check fails closed.

## Key decisions & constraints

1. **The relay dispatcher goes through the router, not around it.** See
   "Failed approaches" and section 1 of the plan's revision.
2. **Revocation must not depend on the daemon cooperating**, credential
   lifetime binds to the daemon's runtime lock, and presence fails closed.
   Orphaned daemons are the reason.
3. **Version skew needs a stated behaviour.** Users do not upgrade daemons
   promptly — this machine ran a v0.1.103 daemon against a v0.3.0 client for
   days. Decide what a phone does against an old protocol before building.
4. **No new recording-based parity gates.** They are a decaying asset: a
   recording can only be produced by the deleted TypeScript reference. The
   relay has no counterpart, so it gets native Rust tests plus an integration
   harness. Convert-and-retire is the standing policy for the existing 65.
5. **The desktop app is deliberately isolated** — it shares no daemon with the
   CLI. Do not "fix" this.
6. **Releasing**: label a PR `release:patch|minor|major`. Unlabelled merges
   accumulate. A release is irreversible — crates.io versions can be yanked but
   never reused, npm's unpublish window shuts after 72 hours.
7. **Never `git stash` in this tree, and never `git checkout --` a directory.**
   There are parallel writers; that has destroyed work before. File-scope every
   restore.
8. **Do not push to origin without an explicit go-ahead.**

## Open questions / blockers

- **The relay's own auth is undecided in one respect**: the plan covers pairing
  and device credentials, but not what the *phone's* session does when the
  daemon's protocol version is older than the platform's. Section 3 of the
  revision says to decide this before building.
- **The parity gates are not in CI.** If the relay is meant to ship through the
  automatic release path, this is worth closing first — it is the gap that let
  the browser-auth bug ship.
- **PR #252 shipped with `main` red for four commits** before anyone noticed,
  because docs commits were pushed straight to `main` without checking CI. Push
  to a branch and let CI speak, or check the run afterwards.
