## Method (non-negotiable, carried from the original handoff)

never failed on purpose has not been shown to bite.

## Divergences found and fixed this session (all had been silently wrong)

- `mask_url` masked only the password, not sensitive **query parameters**, so
  `?password=`/`?token=`/`?api_key=` leaked through `GET /api/databases`.
- `set_database_write_access` silently succeeded for an unknown connection,
  reporting `writeUnlocked: true` while storing nothing.
- The pr-template capitalisation guard used Unicode `is_alphanumeric`; the
  reference capitalises through `/^\w/`, which is **ASCII-only**, so an accented
  branch name was being capitalised when it should not be.

## Key decisions

- Static-vs-param routing: the reference's exact routes are *method-specific*,
  so `DELETE /api/databases/detect` falls through to `:name` and deletes a
  connection named "detect". Axum matches the static segment first, so the
  static paths carry the same DELETE arm and read their name from the URI. See
  the module doc in `routes/database.rs`.
- The new gate deliberately **compares `content-type`**; older git gates strip
  it, which is what hid the `application/json` vs `; charset=utf-8` bug during
  the github API slice.
- `detect` is the only route exempt from the gate's secret-leak assertion: it
  returns the unmasked URL on purpose, because the client needs it to register
  the connection it just found.

## Operational traps (each cost real time)

- **Never run `cargo` while a sweep is running.** The sweeps now refuse to start
  if the cargo lock is held, and are `if __name__ == "__main__"`-guarded so
  importing them to validate anchors does not start a sweep.
- A killed sweep **strands a seed in an untracked file**, which git cannot
  restore. Validate by importing the sweep's `SEEDS` and asserting each `old`
  appears once and each `new` zero times.
- A killed gate leaks its reference daemon (`node --import tsx src/index.ts
  daemon`) on a random port, for days. Sweep with
  `pgrep -f 'import tsx src/index.ts daemon'`. The user's real daemon is
  `dist/index.js daemon --port=4317` — leave it alone.
- **Parity gate invocations differ.** HTTP gates take `./target/debug/nomoreide`;
  MCP gates take the **bare** binary (they append `mcp` themselves).
- MSRV is enforced by `clippy -D warnings` under `rust-version`, **not** by
  building with a 1.77.2 toolchain — that toolchain cannot resolve Tauri's
  edition2024 deps and its failure is unrelated to your code.
- `rustfmt --edition 2021 <files>`, never `cargo fmt -p` (it reformats the peer
  agent's files). rustfmt reflows lines and **staleness sweep anchors** — the
  sweeps validate anchors up front for this reason.
