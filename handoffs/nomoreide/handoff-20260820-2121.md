## Key decisions and constraints

- Local commits only until the full Rust refactoring is finished. Never push, open a PR, or mutate remotes.
- Preserve parallel/user work. Never stash; inspect the tree before each slice and keep commits focused.
- `nomoreide-daemon-client` must never depend directly or transitively on `nomoreide-core`; `scripts/check-rust-dependencies.mjs` enforces this.
- The daemon is the sole owner of live runtime state. MCP, CLI, dashboard, and Tauri are clients.
- Preserve argument-vector execution; never convert structured commands back into shell strings.
- Preserve guarded process termination, protected-process checks, loopback-only daemon access, separate private credentials, and stdout protocol purity.
- TypeScript remains the behavioral reference until black-box parity passes and is removed only in Phase 8.
- Do not infer parity from similarly named Rust/Tauri counterparts.
- Crates.io packaging is deferred; compiling the frozen fixture from the workspace is acceptable for the current GitHub Release binary strategy.
